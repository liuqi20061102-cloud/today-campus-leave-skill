# 今日校园请假条时间编辑 Skill

这是一个用于 Codex 的中文 Skill，面向用户提供的“今日校园”请假条测试截图。

它会按照用户指定的请假日期与时间编辑测试图片，并检查以下内容是否保持一致：

- 请假开始时间、结束时间和总时长
- 手机状态栏时间与页面内当前时间
- 申请、催办、审批、截图、请假开始和结束的先后顺序
- “审批已通过”“即将休假”“休假中”“已结束”等页面状态
- 实际休假时间、续假、销假及相对时间文字
- 原图版式、字体、颜色和其他无关内容

## 安装

```powershell
npx skills@latest add liuqi20061102-cloud/today-campus-leave-skill
```

安装完成后，可以直接要求 Codex 使用 `$image-timeline-editor` 修改今日校园请假条测试截图。

## 示例

```text
使用 $image-timeline-editor，把这张今日校园请假条测试截图的时间改为下周一上午 9:40 到 11:40，并检查所有时间和审批状态。
```

## 使用范围

本 Skill 仅处理用户提供的“今日校园”请假条软件测试素材，不包含真实个人资料或示例截图。使用者应自行确认其拥有处理输入图片的权限。
